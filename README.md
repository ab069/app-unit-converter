# Unit Converter

A clean, offline Android unit converter with Material 3 design.

## Features

- **Length** — mm, cm, m, km, inch, foot, yard, mile
- **Weight** — mg, g, kg, ton, oz, lb
- **Temperature** — Celsius, Fahrenheit, Kelvin
- **Volume** — ml, L, fl oz, cup, pint, quart, gallon
- Swap units instantly with one tap
- Works 100% offline — no internet required

## Tech Stack

- Kotlin + Jetpack Compose + Material 3
- No backend, no permissions needed

## Build

```bash
./gradlew assembleDebug      # debug APK
./gradlew bundleRelease      # signed AAB for Play Store
```
